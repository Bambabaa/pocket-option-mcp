| rsi_momentum_neg | 3.73 | 3.23 | 0.07 | no separation |
| exhaustion_comp | 0.24 | 0.23 | 0.01 | no separation |

**The winning synthetic feature is the simplest one — `body_pct_atr`.** PUT_REV signal bars have bodies averaging 48 % of ATR vs 70 % for other patterns. **Small-bodied red candles (indecision closes) are more predictive than engineered composites.**

### Top-3 synthetic features worth adding to the bot

1. **`candle_efficiency` = body / (high − low)** — gate PUT_REV to `<= 0.55` (most PUT_REV signals have low efficiency). Pseudocode:
   ```js
   const eff = (candle.high - candle.low) > 0 ?
     Math.abs(candle.close - candle.open) / (candle.high - candle.low) : 0;
   const isPutRevCandle = eff <= 0.55;
   ```
2. **`kd_spread_delta` = kd_spread_now − kd_spread_prev** — PUT_REV shows median −8.2 delta (collapse from −2 to −11 in one bar). Gate to `kd_delta <= -5`.
3. **`bbw_expand` = (bbw − bbw_prev) / bbw_prev** — PUT_REV fires during BB expansion (μ +0.20). Gate to `bbw_expand >= 0.05`.

## 📋 Behavioral Pattern Playbook — synthesis

### Pre-signal DNA (PUT_REV — the cash cow)

1. **4-bar green setup** (streak of up moves, HH common)
2. **RSI peaks at 85+ two bars before**, then starts dropping
3. **Stoch K peaks at 86+ two bars before**
4. **K-D spread flips from +8 → −11 across 3 bars** (this is the core event)
5. **BB width expanding** the whole time (+20 % over 5 bars)
6. **Signal bar**: red, small-bodied (body/ATR ≈ 0.48), closes in lower 1/4

### The 5 leading indicators to watch
1. `RSI[-2]` crossing above 80 → *setup alert*
2. `K[-2]` crossing above 85 → *momentum peak*
3. `K-D spread` turning negative → *2-bar warning*
4. `bbw_expand` positive → *volatility regime confirms*
5. `dir` flipping to red after ≥3 green → *trigger candidate*

### The 3 synthetic features to add to the bot

| # | feature | formula | gate |
|---|---|---|---|
| 1 | `candle_efficiency` | `abs(close-open) / (high-low)` | **≤ 0.55** (PUT_REV prefers indecision candle) |
| 2 | `kd_spread_delta` | `kd_now − kd_prev` | **≤ −5** (captures the collapse) |
| 3 | `bbw_expand` | `(bbw − bbw_prev) / bbw_prev` | **≥ 0.05** (confirms volatility regime) |

### Pattern-specific dissection

- **PUT_REV works behaviorally because** K-D collapses from near-zero to ≤ −7 in a single bar. The live "K-D < −3" is too lax — fired signals median −10.9.
- **CALL_REV fails behaviorally because** it fires in the same feature space as PUT_DT (both look oversold), but the market treats "oversold after downtrend" as continuation, not reversal. No gate change can fix that — it's a structural mismatch.
- **PUT_DT works behaviorally because** it's a continuation pattern triggered by genuine downtrend momentum (RSI ~28, clear LL structure). Biggest WR swings come from asset blocklisting (QA1 finding), not gate tweaks.
- **CALL_UT works behaviorally because** RSI > 50 + green candle is a near-unique fingerprint. The live K ≥ 85 gate is a quality filter on top of a clean identity gate.

### Decision architecture — the one rule to ship

```
PUT_REV = (rsi_now ∈ [60,70))
       ∧ (dir = -1)
       ∧ (bbw_now ≥ 30)
       ∧ (rsi_velocity < -12)
       ∧ (kd_spread < -7)             ← tightened from -3 per almost analysis
       ∧ (kd_delta < -5)              ← NEW, synthetic feature
       ∧ (candle_efficiency <= 0.55)  ← NEW, synthetic feature
       ∧ (bbw_expand >= 0.05)         ← NEW, synthetic feature
```

Expected behavior: **captures ~80 of the 95 "pure" PUT_REV leaf**, filters the 291 "almost" false positives, adds behavioral alignment to the QA1 statistical gates.

### The "almost" filter (false-positive rejection)

- If bar meets core gates but `kd_spread > −7`: **reject, wait for collapse**.
- If bar meets core gates but `kd_delta > −5`: **reject, the crash hasn't happened yet**.
- If bar has body/ATR > 0.55: **reject, too much conviction = likely continuation not reversal**.

## ⚠️ Caveats

1. **Cluster sizes were imbalanced** — k=6 produced 2 meaningful clusters and 4 tiny outlier clusters. k-means with k=4 or DBSCAN would likely give cleaner separation; the current setup is usable but not optimal.
2. **PCA was not implemented** (Node library constraint). Projecting 25 dims → 2D via PCA would reveal visual cluster structure; current output relies on z-score inspection of centroids.
3. **Sequence mining was n-gram, not PrefixSpan** — good enough for the 3-bar patterns we care about, but misses longer behavioral motifs (5-7 bar sequences).
4. **Decision tree is CART from scratch**, max depth 5, min samples 20. No pruning, no ensemble. A proper random forest would likely push accuracy to 95%+.
5. **No out-of-sample validation across DBs** — 70/30 split was random across all 5 DBs. True time-series holdout (train v2+V3, test V4+current) would be stricter but sample size becomes thin.
6. **kd_delta, candle_efficiency, bbw_expand are not yet computed in `indicators.js`** — they're proposed. Wire them up before enabling the new gates live.
